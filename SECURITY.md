# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability within Grab Tools, please report it responsibly. We take security issues very seriously.

- **Scope:** This policy covers all repositories and services associated with Grab Tools.
- **Reporting:** Contact the maintainers directly or open a private advisory on GitHub.

## Quality Standards

Unchecked, AI-generated, or sloppy responses, pull requests, or security contributions will not be tolerated. All code and security patches must be thoroughly vetted, verified, and manually reviewed before submission.
